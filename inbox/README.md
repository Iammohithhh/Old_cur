# Inbox

Drop **anything** here: rough notes, a Google Doc saved as Markdown (File → Download → Markdown), a Notion export, a pasted AI chat, bullet points, or a photo of handwritten notes.

Then ask an AI assistant (Claude Code or Codex) to **"process the inbox"**. The rules it follows are in [AGENTS.md](../AGENTS.md).

Everything in this folder except this README is git-ignored. Raw notes stay on your machine and never reach the public repo.
Processed originals are moved to `inbox/_processed/`.
